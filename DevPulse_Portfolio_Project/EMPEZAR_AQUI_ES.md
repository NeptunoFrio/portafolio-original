# Empieza aquí

**DevPulse** es un panel web de monitoreo de servicios. Usa Python + FastAPI, SQLite y TypeScript.

1. Descomprime el ZIP.
2. Sigue los pasos del `README.md`.
3. Ejecuta la API y el frontend.
4. Prueba agregar servicios y resolver incidentes.
5. Personaliza el diseño o agrega una función propia.
6. Toma capturas reales de la aplicación funcionando para tu portafolio.

Importante: esta versión registra chequeos que se envían a la API; todavía no revisa servicios automáticamente cada cierto tiempo. Puedes convertir eso en una mejora de tu segunda versión.
